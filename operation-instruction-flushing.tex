
加药检修前，
如果有反冲洗条件（反冲洗不影响处理工艺的情况下），
可以使用非腐蚀性（例如水）介质冲洗检修工位计量泵、计量泵附件、阀门、管道，
使操作人员更安全。
\par反冲洗控制阀位置请参考第\pageref{sec:sg1-1}页第\ref{sec:sg1-1}节的图\ref{fig:g02g03}。
以泵1为例，反冲洗操作流程如下：
\begin{enumerate}
    \item 关闭 泵1反冲洗隔离阀。
    \item 打开 泵1反冲洗出水阀。
    \item 打开 泵1反冲洗进水阀，冲洗检修范围内的化学药液。
    \item 关闭 泵1反冲洗进水阀。
    \item 关闭 泵1反冲洗出水阀。
\end{enumerate}
