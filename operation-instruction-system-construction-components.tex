\subsection{加药装置功能特点}
    加药装置有如下功能特点：
    \begin{itemize}
         \item 配备阻尼器及背压阀，消除计量泵投加时产生的脉动。
         \item 配备泄压阀，系统过压时，自动泄压阀避免设备及管道损坏。
         \item 配备隔膜压力表，指示系统当前压力，及显示计量泵工作状态。
         \item 配备反冲洗及检修排液系统，检修前可释放系统压力，排出管道内介质，并使用水等非腐蚀性介质冲洗管道，保证检修人员安全。
    \end{itemize}
